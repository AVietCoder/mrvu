Search Console & GA4

Dữ liệu thật từ Google của chính website bạn: từ khóa nào mang click, trang nào mang khách, việc gì nên làm trước. Kết nối một lần, đồng bộ bất cứ lúc nào.

Đang kiểm tra kết nối…
Chưa kết nối
1

Tạo service account trong Google Cloud (làm một lần)

  1. Vào console.cloud.google.com, tạo project mới (ví dụ “MrVu SEO Studio”).
  2. APIs & Services → Library: bật Google Search Console API và Google Analytics Data API.
  3. IAM & Admin → Service Accounts → Create, đặt tên bất kỳ, bỏ qua phần phân quyền.
  4. Mở service account vừa tạo → Keys → Add key → Create new key → JSON. Trình duyệt tải về một file .json.

File được lưu trong thư mục công cụ trên máy bạn (google-service-account.json). Giữ kín file này, không gửi cho ai.

2

Cấp quyền xem cho service account

(tải file khóa ở bước 1 để thấy email)
  1. Search Console → Cài đặt → Người dùng và quyền → Thêm người dùng → dán email trên → quyền Hạn chế.
  2. Google Analytics → Quản trị → Quản lý quyền truy cập thuộc tính → + → dán email → vai trò Người xem.
3

Chọn website và thuộc tính GA4

Property ID nằm ở GA4 → Quản trị → Cài đặt thuộc tính (dãy số, không phải mã G-XXXX). Để trống nếu chưa dùng GA4.

4

Đồng bộ dữ liệu

Bấm Đồng bộ dữ liệu ở trên. Lần đầu mất khoảng 1 phút. Dữ liệu Google chậm khoảng 3 ngày, nên đồng bộ mỗi tuần một lần là đủ.
