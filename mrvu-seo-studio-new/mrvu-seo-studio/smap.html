Tạo khóa PageSpeed Insights API (khoảng 2 phút)

  1. Vào console.cloud.google.com, chọn đúng project đã dùng cho Search Console.
  2. APIs & Services → Library, tìm PageSpeed Insights API, bấm Enable.
  3. APIs & Services → Credentials → Create credentials → API key. Copy khóa (bắt đầu bằng AIza).
  4. Bấm vào khóa vừa tạo → API restrictions → Restrict key → chọn PageSpeed Insights API → Save (để khóa chỉ dùng được cho việc đo tốc độ).
  5. Dán khóa vào ô ở trên và bấm Lưu. Miễn phí, khoảng 25.000 lượt đo mỗi ngày.
