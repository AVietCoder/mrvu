Thêm website

Kết nối

Tạo Application Password trong WordPress: Thành viên → Hồ sơ → Application Passwords, đặt tên "Mr.Vũ SEO Studio", bấm Thêm và copy chuỗi được tạo (không phải mật khẩu đăng nhập).

Công cụ gửi POST JSON gồm title, slug, content_html, meta_title, meta_description, tags, images (base64)… kèm header Authorization: Bearer <mã bảo mật>. Website trả về {"id": ..., "url": ...}. Chi tiết trong HUONG_DAN.md để gửi cho người làm web.

Cách đăng bài

Chọn Yoast/Rank Math để công cụ ghi luôn meta title, meta description, từ khóa chính. Cần cài file mrvu-seo-studio-seo-meta.php (trong thư mục wordpress-plugin) vào website một lần.

Lịch tự động

Bài được rải đều trong khung giờ. Lịch chỉ chạy khi cửa sổ Mr.Vũ SEO Studio đang mở trên máy.

Mẹo: lấy từ khóa từ tab Tra cứu Volume, ưu tiên từ dài, ý định tìm hiểu rõ ràng.
